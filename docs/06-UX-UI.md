# 06 — Diseño y experiencia de usuario

## Navegación principal (solo cinco entradas)
1. Inicio
2. Comercial
3. Proyectos y producción
4. Administración
5. Recursos del estudio
Configuración accesible desde perfil/menú secundario.

## Patrones
- Sidebar compacta, breadcrumb, búsqueda global, botón crear, favoritos, actividad.
- Filtro persistente de línea: Todas / Arquitectura / Visualización; no cambia de aplicación ni crea dashboard separado.
- Subnavegación contextual dentro de cada área, no 10 módulos principales.
- Listas con tabla, tarjetas, Kanban y calendario donde tenga sentido; filtros guardables.
- Fichas de cliente/proyecto con pestañas y panel de actividad, evitando pantallas duplicadas.
- Diseñar estados vacíos, loading, error, permisos insuficientes, confirmaciones y deshacer.
- Formularios con guardado explícito y advertencia de cambios sin guardar.
- Diseño mobile usable; priorizar escritorio para edición compleja y PDFs.

## Dirección visual
Minimalista tipo Notion con refinamiento arquitectónico: tipografía sobria, aire, jerarquía clara, neutros cálidos, acento discreto y modo claro/oscuro opcional. Accesibilidad: contraste, teclado, focus visible, etiquetas, feedback de errores.

## Pantallas esenciales
Inicio; Comercial (pipeline, clientes, cotizaciones, editor, catálogo, presets, marketing); Producción (proyectos, detalle, paquetes, tareas, calendario, entregables, cambios); Administración (cobros, gastos, repartos, tiempo, reportes); Recursos (documentos, plantillas, membretes, biblioteca, procedimientos); Configuración.

## Regla de UX
La creación de una cotización no debe exigir registrar información innecesaria. Debe existir modo rápido y modo propuesta completa.
