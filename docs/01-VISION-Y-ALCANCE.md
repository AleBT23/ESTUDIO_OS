# 01 — Visión y alcance

## Visión
ESTUDIO OS es un sistema operativo privado para un estudio de arquitectura en México. Centraliza captación, cotización, producción, cobros, conocimiento y medición de rentabilidad.

## Organización visible
- **Inicio**: dashboard unificado con filtro `Todas / Arquitectura / Visualización`.
- **Comercial**: clientes, oportunidades, presupuestos, servicios/presets, marketing/portafolio.
- **Proyectos y producción**: proyectos, paquetes de servicios, fases, tareas, calendario, entregables, revisiones, cambios y extras.
- **Administración**: cobros, gastos, honorarios, colaboradores, tiempo, rentabilidad, reportes.
- **Recursos del estudio**: plantillas, documentos, membretes, biblioteca BIM/técnica, procedimientos.
- **Configuración**: usuarios, roles, líneas de negocio, moneda, impuestos, respaldos.

## Líneas de negocio
1. Arquitectura: residencial, interiorismo, levantamientos, proyecto ejecutivo, trámites y servicios relacionados.
2. Visualización arquitectónica: renders, recorridos, experiencias 360, animación y servicios para otros estudios.
Son **clasificaciones configurables**, no bases de datos ni paneles separados. Un proyecto puede tener paquetes de ambas líneas; los ingresos y horas se atribuyen por paquete y se consolidan a nivel proyecto y estudio.

## Principios
- Captura única de datos y relaciones entre áreas.
- Los presets reducen trabajo repetitivo; no imponen procesos rígidos.
- Cada acción comercial puede convertirse en trabajo operativo sin duplicar información.
- Datos exportables, auditables y respaldados.
- Interfaz sencilla, inspirada en la flexibilidad de Notion, sin recrear un editor universal.

## Fuera de alcance inicial salvo decisión posterior
Contabilidad fiscal certificada, facturación CFDI, nómina, integración directa con Revit, sincronización bidireccional con WhatsApp, CRM de campañas publicitarias de pago y aplicación móvil nativa. Se pueden guardar enlaces y referencias externas.
